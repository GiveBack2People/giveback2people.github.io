# GiveBack2People logo kit

Approved direction: **Lift** — a shared resource, lifted by the community.

Start with `png/avatar-dark.png` for GitHub and `svg/horizontal-color-light.svg` for a light website header. Use `svg/horizontal-color-dark.svg` for a dark website header.

- `svg/`: editable vector masters — symbols, horizontal and stacked lockups, wordmarks, one-color versions, small-size cuts, and avatars.
- `png/`: high-resolution exports with transparent backgrounds, plus opaque GitHub avatars.
- `web/`: favicon ICO/SVG/PNG, Apple touch icon, app icons, manifest, and installation snippet.
- `guidelines/usage-guide.md`: sizes, spacing, colors, typography, and usage instructions.
- `brand-preview.png`: light/dark presentation, README example, avatar crop, and small-size review.

Upload or install the assets when ready. No GitHub organization settings or live website files have been changed.
