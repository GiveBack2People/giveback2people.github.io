# GiveBack2People — Lift

The open cradle represents a community lifting a useful resource toward the next person. A diamond represents curated knowledge, tools, and digital craftsmanship. Preserve the relationship between these two shapes.

## Choose the right file

| Use | File |
|---|---|
| GitHub organization avatar | `png/avatar-dark.png` or `png/avatar-light.png` |
| Website on a white background | `svg/horizontal-color-light.svg` |
| Website on a dark background | `svg/horizontal-color-dark.svg` |
| Square or narrow composition | `svg/stacked-color-light.svg` or `svg/stacked-color-dark.svg` |
| Standalone symbol | `svg/symbol-color-light.svg` |
| One-color applications | Any `black`, `white`, or `indigo` SVG |
| Browser favicon | `web/favicon.ico` and `web/favicon.svg` |
| 16-pixel inline symbol | `svg/symbol-small-indigo.svg` or `svg/symbol-small-white.svg` |

All logo SVGs use outlined lettering and solid vector paths. Transparent PNG equivalents are included. Avatar PNGs include an opaque background so the appearance does not depend on the surrounding interface. “Color-light” and “color-dark” name the intended background; the transparent files do not draw that background.

## Size and clear space

Keep a clear zone at least one cradle-bar thickness around the visible artwork: 32 units on the original 256-unit symbol canvas. Preserve the square canvas padding for avatars; it accommodates a circular crop. Do not add a circular crop to the upload itself.

Recommended digital minimums: 32 pixels for the two-color symbol, 16 pixels for the small-size monochrome symbol, 240 pixels wide for the horizontal lockup, 200 pixels wide for the stacked lockup, and 180 pixels wide for the wordmark alone. These refer to the complete SVG canvas. Use larger sizes where possible.

The small-size cut retains the cradle but simplifies the diamond to vertices on a 16-pixel grid, increasing its separation from the cradle. Use it at 16–24 pixels. The favicon uses this cut in white on an obsidian tile for consistent visibility across browser themes.

## Colors

| Color | HEX | RGB |
|---|---|---|
| Indigo | #6366F1 | 99, 102, 241 |
| Cyan | #06B6D4 | 6, 182, 212 |
| Obsidian | #0F172A | 15, 23, 42 |
| White | #FFFFFF | 255, 255, 255 |

The cradle is indigo and the diamond cyan. Use obsidian lettering on white and white lettering on obsidian. Black, white, and indigo monochrome versions preserve the entire silhouette. White versions retain the approved geometry; visual review did not warrant a separate thinner construction. These are RGB digital masters; specify print colors with your printer against a physical proof rather than treating unverified CMYK or Pantone conversions as exact matches.

## Typography and copy

The approved wordmark is derived from Segoe UI Bold and supplied as outlines. Use the supplied artwork rather than retyping it. Font software is not included; the logo does not require an installed font. Any separate use or redistribution of font software requires the appropriate license.

For interface text, use the platform's system sans-serif stack. Keep the tagline separate from compact logo lockups:

“Open-source tools, curated creative resources, and practical knowledge built to pay it forward.”

## Web installation

Copy the contents of `web/` into your site's `/icons/` directory and insert `head-snippet.html` into the document head. If you use another asset path, update the snippet and manifest icon paths together. The 192- and 512-pixel icons are ordinary app icons, not maskable icons.

## Preserve the identity

Keep proportions, colors, spacing, and orientation intact. Use flat fills. Avoid shadows, gradients, added outlines, busy backgrounds, and rearranging the diamond. The logo identifies the organization; project names such as Design Resources Hub should appear as separate text.
